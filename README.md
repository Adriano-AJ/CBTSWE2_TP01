# CBTSWE2_TP01

## Descrição
Um projeto em C# que implementa um sistema de gerenciamento de livros utilizando uma API web com ASP.NET Core. O projeto realiza operações de busca e apresentação de informações sobre livros, incluindo detalhes de nomes, autores e descrições através de rotas HTTP.

## Autores
- **ADRIANO JÚNIOR DE SOUZA ALMEIDA** - CB3030644

## Funcionalidades
- Busca de livros por ID
- Consulta de nomes de livros
- Listagem de autores
- Descrição detalhada de livros
- Interface HTML para apresentação de livros com integração de dados

## Tecnologias
- **Linguagem:** C#
- **Framework:** ASP.NET Core
- **Servidor Web:** Kestrel
- **Armazenamento:** CSV
